🛠️ 技术实现

  • Fluent UI - Microsoft的设计系统，现代化界面
  • React Router - 客户端路由管理

  • i18next - 国际化支持

src/ ├── types/announcement.ts # 类型定义 ├── services/announcementService.ts # 业务逻辑 ├── hooks/useAnnouncements.ts # React Hook ├── pages/Announcements.tsx # 公告页面 ├── api/announcements.ts # API配置 └── components/Header.tsx # 更新的导航栏

🚀 使用方法

  1. 系统会自动检查是否有活跃公告
  2. 如果有公告，导航栏会显示公告按钮（带红点提示）
  3. 点击公告按钮进入公告页面
  4. 公告页面显示所有活跃公告，支持类型和优先级标识
  5. 过期的公告会自动隐藏

⚙️ 配置说明

当前使用模拟数据进行演示。要连接真实API：

  1. 更新 announcementService.ts 中的API地址
  2. 替换模拟数据逻辑为真实的fetch调用
  3. 确保后端API返回正确的数据格式
