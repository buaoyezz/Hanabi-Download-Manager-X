# Example L10N ARB

这个目录放的是可直接参考的语言包示例。

## 怎么用

1. 复制你需要的 `.arb` 文件到应用的 `lang` 目录。
2. 在软件里点击“刷新语言包”。
3. 在“界面语言”里切换到对应语言。
4. 如果语言包里写了 `@@fontLocale`，应用会把这个语言包归到对应的“字体类别”。
5. 如果语言包里写了 `@@defaultFont`，应用会把它当成该字体类别的默认显示字体。
6. 如果语言包里写了 `@@defaultEnglishFont`，应用会把它当成这个语言上下文下的默认英文字体。

## 支持的元数据

- `@@locale`
  - 语言包的 locale 标签，例如 `zh_Hant`、`meow`
- `@@languageName`
  - 设置页里显示的语言名
- `@@fontLocale`
  - 可选，指定这个语言包复用哪个字体类别
  - 例如 `meow -> zh`，表示喵喵语直接复用简体中文字体设置
  - 例如 `zh_TW -> zh_Hant`，表示它使用“繁体中文”这条字体设置
- `@@defaultFont`
  - 该字体类别建议使用的默认字体
  - 用户后续仍然可以在设置页里单独改掉
  - 对于 `meow -> zh` 这类语言包，它就是“喵语上下文下的默认中文字体”
- `@@defaultEnglishFont`
  - 可选，指定这个语言在启用时默认使用的英文字体
  - 适合 `meow -> zh` 这类“主脚本是中文，但界面里仍有英文标题/产品名”的语言包
- `author` / `version` / `source`
  - 可选，仅用于说明来源

## 字体规则

- 英文主字体默认是 `Segoe UI`
- 中文默认字体是 `Noto Sans SC`
- 中文还会自动带上 `Microsoft YaHei UI` / `Microsoft YaHei` 作为兜底
- 设置页默认只显示英文和中文两条字体设置
- 当前界面语言如果实际归属到别的字体类别，例如 `zh_Hant` 或 `ja`，会自动显示对应那一条
- 语言包如果声明了 `@@fontLocale`，会直接复用对应类别的字体设置，不会自动在设置页里再新增一行
- 当前语言的主脚本会优先使用该语言包声明的 `@@defaultFont`
- 当前语言里的英文内容会优先使用该语言包声明的 `@@defaultEnglishFont`
- 如果某个键没有翻译，程序会自动回退到内置语言文本

## 示例说明

- `app_zh_Hant.arb`
  - 一个可用的繁体中文示例
  - 演示如何同时给“繁体中文”和英文内容指定默认字体
- `app_meow.arb`
  - 一个娱乐性质的非官方示例
  - 演示如何让第三方语言包继承简体中文类别，同时分别指定中文和英文默认字体

## 注意

- `@@defaultFont` 只是“默认建议值”，不是强制内嵌字体。
- `@@defaultEnglishFont` 也是默认建议值，用户仍然可以在设置页覆盖。
- 如果目标机器没有安装对应字体，Flutter 会继续走后续回退链。
- 想让某种字体 100% 可用，仍然建议用户自行安装字体或导入自定义字体。
