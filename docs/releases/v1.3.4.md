# Hanabi Download Manager X v1.3.4 正式版更新日志

## 重点
> 本次正式版重点修复大文件下载完成后的卡顿问题，并优化多线程下载的落盘流程。
> 多分段任务现在会直接写入同一个临时文件，不再在完成后进行耗时的大文件合并。
> 同时改进通知页、速度曲线、后台资源占用和 Windows 崩溃报告链路，让日常使用更稳定。

## 下载核心与稳定性
[+] 多分段下载改为边下边写入最终临时文件，完成时只做轻量校验和重命名，减少大文件完成阶段卡顿。
[+] 保留分段字节数校验和最终文件大小校验，继续防止因下载核心异常导致的不完整文件。
[+] 兼容旧版 `.part` 分段文件，恢复任务时会迁移到新的直接写入文件。
[+] 优化大文件完成处理路径，避免 UI 长时间无响应。
[+] 修复部分 Windows daemon 崩溃报告读取路径在 C++ 构造参数上的兼容问题。

## 桌面 UI 与体验
[+] 重新设计通知页卡片布局和图标层级，提升公告内容的可读性。
[+] 调整通知页刷新按钮位置，使其与同步状态和内容区对齐。
[+] 修复速度曲线偶发不显示的问题，当前速度有值时会立即渲染曲线。
[+] 修复速度曲线颜色被暂停/失败状态覆盖的问题，曲线颜色现在始终遵循用户设置。
[+] 速度曲线设置改为共享配置服务，外观设置变更后下载卡片会即时刷新。

## 性能与后台行为
[+] 优化窗口隐藏后的前台服务和 UI 渲染状态，降低后台运行时的资源占用。
[+] 优化任务列表渲染与统计计算，减少不必要的查找和重建。
[+] 优化系统托盘任务信息输出，后台状态展示更轻量。

## 测试与验证
[+] 增加多分段直接写入、旧分段迁移、速度曲线渲染等测试覆盖。
[+] 通过下载核心相关测试、速度曲线测试、daemon Debug 构建和相关静态分析。
