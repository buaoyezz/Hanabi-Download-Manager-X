## 快速开始
> [!important]
> 环境要求
> - Flutter SDK 3.0.0+
> - Windows 10/11

### 运行

```bash
git clone https://github.com/buaoyezz/hanabi-download-manager-x.git
cd hanabi-download-manager-x
flutter pub get
flutter run
```

> [!TIP]
> 其实可使用 `build_release.bat` 快速构建
> 注意`rhttp`可能存在的编译失败问题

### 构建

```bash
build_release.bat
```

或：

```bash
flutter build windows --release
```
