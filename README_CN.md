<a name="快速开始"></a>
## 快速开始

### 环境要求
- Flutter SDK
- Python 3.12.6
- 相关依赖（详见 `requirements.txt`）

### 安装步骤

1. 安装 Python 依赖
   ```bash
   pip install -r python/requirements.txt
   ```

2. 运行 Flutter 应用
   ```bash
   flutter pub get
   flutter run
   ```
