📋 Test Instructions

  1. Install the HDM-X browser extension
  2. Make sure link detection is enabled in the extension popup settings
  3. Hover over links in the "Direct Download Links" section - HDM-X buttons should appear smoothly
  4. Move mouse away - buttons should disappear after a short delay
  5. Hover over links in the "Non-Direct Links" section - NO buttons should appear
  6. Test settings toggle:
    • Disable link detection in extension settings
    • Refresh this page
    • No buttons should appear anywhere when hovering
    • Re-enable link detection and refresh
    • Buttons should appear again for direct download links only
  7. Wait 3 seconds for dynamic content to load and test mutation observer
